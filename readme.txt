WordPress Gutenberg Block para Botões Grandes com até 5 botões por linha, links rápidos, estilos institucionais e suporte multilíngue.

== Description ==

**luiz0067 Big Button** é um plugin WordPress nativo e completo que adiciona um bloco Gutenberg moderno para criação e gerenciamento de botões de destaque (Big Buttons) em linhas flexíveis de 1 a 5 botões.

Totalmente compatível com o bloco legado `cms-adm/big-button` e o tema institucional da Prefeitura (`#01913a`), o plugin oferece edição WYSIWYG fluida, controles inline para adicionar e remover botões, alinhamento flexível e customização de cores.

### Features
* **Até 5 Botões por Linha**: Layout adaptativo ou fixo com 1 a 5 colunas.
* **100% WYSIWYG**: O que você vê no editor Gutenberg é exatamente o que aparece no site público.
* **Ações Rápidas Inline**: Adicione (`+`) ou remova (`-`) botões diretamente no canvas visual com inputs de link rápido.
* **Estilo Institucional Prefeitura**: Verde institucional `#01913a` com hover suave e sombra de elevação.
* **Múltiplos Estilos**: Padrão Branco Institucional, Verde Sólido, Contorno (Outline) e Bordas Arredondadas (Pill).
* **Compatibilidade Retroativa Integral**: Suporte automático aos posts legados criados com `cms-adm/big-button`.
* **Zero Build Step**: 100% Vanilla JavaScript ES5 puro com `wp.element.createElement`. Não requer npm, node ou webpack.
* **Multilíngue Completo (i18n)**:
  * 🇧🇷 Português do Brasil (`pt_BR`)
  * 🇺🇸 Inglês (`en_US`)
  * 🇪🇸 Espanhol (`es_ES`)
  * 🇮🇹 Italiano (`it_IT`)

== Installation ==

1. Envie a pasta do plugin para o diretório `/wp-content/plugins/`, ou instale o arquivo ZIP pelo painel do WordPress em **Plugins > Adicionar Novo > Enviar Plugin**.
2. Ative o plugin através do menu **Plugins** no WordPress.
3. Abra qualquer Post ou Página no editor de blocos (Gutenberg).
4. Pesquise por **"Botões Grandes"** ou **"big button"** no inseridor de blocos.
5. Digite o texto nos botões, insira os links desejados e publique!
